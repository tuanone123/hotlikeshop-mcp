# Changelog

All notable changes to the HOTLIKESHOP MCP documentation are recorded here.

## [1.0.0] - 2026-08-27

### Added
- Initial public release of the HOTLIKESHOP MCP Server listing.
- 17 tools across 3 groups: **Lookup** (9, free/keyless), **Purchase** (4, API key), **MMO utilities** (4, free).
- Remote **Streamable HTTP** endpoint: `https://hotlikeshop.com/api/mcp`.
- Bilingual documentation (English + Tiếng Việt).
- Client config examples for Claude Desktop, Cursor and native HTTP clients.
- MCP registry manifest (`server.json`).
